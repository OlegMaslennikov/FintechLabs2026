Сдача лабораторной работы № 3 «Аукцион»

Репозиторий курса: https://github.com/OlegMaslennikov/FintechLabs2026

Отправь свой username старосте.

Прими приглашение преподавателя к работе с репозиторием.

Склонируй репозиторий на свой компьютер:

git clone https://github.com/OlegMaslennikov/FintechLabs2026.git
cd FintechLabs2026

Создай собственную ветку. Вместо ivanov-ivan укажи свою фамилию и имя латиницей:

git checkout -b lab3-ivanov-ivan

Выполни работу в папке Lab3_Auction/. Не изменяй файлы других лабораторных работ и не отправляй изменения непосредственно в main.

Добавь свою работу в Git:

git add Lab3_Auction/
git commit -m "Lab 3 - Ivanov Ivan"
git push -u origin lab3-ivanov-ivan

Открой репозиторий на GitHub. Нажми Compare & pull request, если GitHub предложит эту кнопку, и создай Pull Request в ветку main.

Назови запрос Lab 3 — Иванов Иван и дождись проверки преподавателем.

Если потребуются исправления, внеси их в ту же ветку, сделай новый коммит и отправь его командой git push. Создавать новый Pull Request не нужно.
